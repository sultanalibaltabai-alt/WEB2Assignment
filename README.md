# WEB Technologies 1 - Assignment 2: Advanced CSS

This repository contains the completed Assignment 2 for the WEB Technologies 1 course at Astana IT University (AITU). The project is a multi-page website demonstrating CSS Grid, Flexbox layouts, interactive galleries, and semantic HTML structuring.

## Project Structure
- index.html - Main landing page of the application.
- layout.html - Page showcasing CSS Grid structures and element layouts.
- gallery.html - Interactive meme image gallery built with CSS Grid and hover overlays.
- portfolio.html - Portfolio showcase page containing project cards.
- style.css - Central stylesheet containing layout rules, CSS Grid definitions, and hover effects.
- Mems/ - Local directory containing image assets for the gallery.

## Key Features Implemented
1. CSS Grid Gallery: Configured a fixed 3-column layout using `grid-template-columns: repeat(3, 1fr)` with uniform gap spacing.
2. Image Styling: Applied `object-fit: cover` with fixed height constraints to maintain proper aspect ratios without image distortion.
3. Interactive Overlays: Implemented dynamic hover effects (`.overlay`) that display text captions smoothly on mouse hover.
4. Semantic Markup: Structured all pages using semantic HTML elements such as `<header>`, `<main>`, `<section>`, and `<footer>`.
